GAME GUIDE 01

Bollinger Run

過去の相場を「読む」のではなく、チャートのうねりを操作感として体験するアクションゲームです。

ゲームを開始

遊び方

画面をタップしている間、プレイヤーは上方向へ進み、指を離すと下方向へ進みます。PCではスペースキーの長押しでも操作できます。ローソク足に沿って続く上下のバンドから外れるとゲーム終了です。

  1. ニックネームと難易度を選び、STARTを押します。
  2. カウントダウン後、タップまたはスペースキーで上下を調整します。
  3. バンド内を進み、できるだけ先の年月を目指します。
  4. 結果画面で到達年月、進行率、時間を確認します。

2つの難易度

初心者開始時はおおむね±3σの幅。ゲームに慣れたい人向けです。
上級者開始時はおおむね±1.5σの幅。小さな操作ミスも結果に出やすい設定です。
共通約2秒ごとに難易度が上がり、最長約5分で全期間を走破します。

相場の出来事

プレイ中には、金融政策、相場急変、NISA、世界的な出来事など、チャート上の時期に対応したメモが表示されます。2011年3月15日、2024年8月5日などの大きな変動では、終値ベースの前営業日比も表示します。

この情報はゲームの背景を理解するための補助です。原因と値動きの関係を単純化して断定せず、詳しく確認したい人が一次情報へ進めるよう参照先を示しています。

データと記録

ゲーム内の日経平均データは2010年2月から2026年8月7日までを収録しています。日経平均株価および関連指数の知的財産権は日本経済新聞社に帰属します。公開・収益化時は利用条件を継続確認します。

記録の保存
ランキングAPIが利用できない環境では、結果はこのブラウザ内に保存されます。ブラウザデータの削除、シークレットモード、端末変更では記録を引き継げません。

主な確認先

  • 日経平均プロフィル：上昇・下落記録
  • 首相官邸：歴代内閣
  • 日本銀行：金融政策決定会合
  • 金融庁：NISA特設ウェブサイト

制作意図

長期間のチャートを眺めるだけでは実感しにくい「穏やかな時期と急変する時期の差」を、短時間の操作に置き換えられないかと考えて制作しました。投資成果を競うゲームではなく、相場の変化をゲームとして体験することが目的です。

重要
本作は学習・娯楽目的です。特定の金融商品への投資を勧めるものではなく、将来の値動きを予測・保証しません。
