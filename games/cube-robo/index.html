CONTROLS

PLAYER 1 vs CPU 1 / 各3機。最後に残った1機が勝利。

MOVE / 移動

PCは矢印キー。スマホは左スティック。自機の後ろから追従する視点です。

BOOST / 加速

同じ方向を2回入力。2回目を長押しすると燃料が続く間ブースト。スマホのブーストボタンも長押しできます。

JUMP / ジャンプ

SPACEまたはジャンプボタン。空中でもう一度押すとダッシュ、長押しで継続。空中ダッシュは着地まで2回。

F / BEAM

敵を自動照準し、発射後は34m/sで直進する単発ビーム。横移動・ジャンプ・遮蔽物で回避できます。

D / BOMB · S / SABER

ボムは山なりに飛び、直撃150・爆風50ダメージ（空中では110・37）。サーベルは踏み込んで180ダメージ。斬撃の瞬間だけ命中します。

E / SHIELD

3秒間の無敵。30秒ごとに使用できます。被弾が重なるとダウンし、自動で起き上がります。残機があれば撃破後に復帰します。

スマホは横画面専用。左移動と右攻撃を同時操作できます。Esc / Ⅱでポーズ。
