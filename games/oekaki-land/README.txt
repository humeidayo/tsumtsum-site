# おえかきランド

4歳向けの横画面知育・おえかきPWAです。

## 主な機能
- ひらがな（基本46文字＋濁点・半濁点・小文字・ゔ）のなぞり練習
- おなまえなぞり（最大12文字、保護者設定から変更）
- なぞりえ30種類
- ぬりえ30種類
- じゆうちょう
- 日本語読み上げ
- 効果音 / 簡易BGM
- PNG保存
- PWA / オフライン
- 横画面
- ピンチ・ダブルタップ・長押し等の誤操作対策

## 起動方法
PWA機能やService Workerを正しく使うには、index.htmlを直接ダブルクリックではなくHTTP(S)経由で開いてください。

例:
python -m http.server 8000

その後:
http://localhost:8000/

## おとな設定
ホーム右下の「⚙️ おとな」を3秒長押し。

## 注意
音声は端末・ブラウザのSpeechSynthesis（日本語音声）を使用するため、声質は環境により異なります。
